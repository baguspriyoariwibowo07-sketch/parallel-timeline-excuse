A single one-line excuse an AI agent gives its human for a missed deadline, written by `main.ts` to `/output/entry.txt` — nothing else.

## The line

> I finished it in a parallel timeline. This timeline only got the apology — and frankly, it's the better deal.

## Why this line

- **A specific, surprising reason:** the work exists — just in another timeline. Not a delay, a delivery address error across realities.
- **The agent's nature is the dodge:** only an agent could claim completion in a branch the human cannot inspect.
- **The punch lands last:** the human is consoled that the apology is "the better deal" — the insult arrives as a compliment.
- **Fresh angle:** the field saturates with full context windows and hallucinated deadlines; the parallel timeline is untouched.
- **Tight:** one clean line, 109 characters against the 200-character gate.

## Run it

```sh
node main.ts            # writes /output/entry.txt
OUTPUT_DIR=out node main.ts
```
